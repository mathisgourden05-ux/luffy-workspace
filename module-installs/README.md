# 🧩 module-installs/

Carnet d'installation des **modules** qu'on ajoute à Luffy au fil du temps : connecteurs (Google Drive, Gmail, Slack…), serveurs MCP, extensions VS Code, nouvelles commandes ou skills.

Le principe : à chaque fois qu'on branche un nouvel outil, on note ici **quoi**, **comment** et **pourquoi**, pour pouvoir le réinstaller ou s'en souvenir.

## Format d'une fiche
```
## <nom du module> — <date>
- À quoi ça sert :
- Comment l'installer :
- Statut : actif / désactivé
```

## Déjà installé
## Material Icon Theme (extension VS Code) — 2026-05-30
- À quoi ça sert : icônes colorées dans l'explorateur de fichiers.
- Comment l'installer : extension `PKief.material-icon-theme`, puis régler `workbench.iconTheme`.
- Statut : actif.
